# مشروع صفحة Leon

صفحة تعريفية لوكالة Leon، بتعرض الخدمات والأعمال ونبذة عن الموقع ووسائل التواصل. الصفحة مناسبة لشاشات الكمبيوتر والموبايل.

## أقسام الصفحة

1. **الهيدر:** شعار الموقع وقائمة التنقل.
2. **الواجهة:** صورة الجبال مع عنوان ونص ترحيبي.
3. **المميزات:** ثلاث نقاط تعريفية عن الوكالة.
4. **الخدمات:** عرض خدمات التصميم وتطوير المواقع.
5. **الأعمال:** صور ونماذج أعمال، مع زر لعرض المزيد.
6. **نبذة عن الموقع:** صورة ونص تعريفي.
7. **التواصل:** البريد الإلكتروني وأيقونات التواصل.
8. **الفوتر:** حقوق الموقع في نهاية الصفحة.

## ملفات المشروع

- `index.html`: الصفحة الرئيسية.
- `css/style.css`: تنسيق الصفحة.
- `images/`: الصور والشعار.
- `icons/`: الأيقونات.
- `fonts/`: الخطوط.
